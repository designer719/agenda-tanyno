# Agenda de demandas · Tanyno

Página da agenda do Rodrigo (marketing e design da Tanyno), publicada com o GitHub Pages.

- `index.html`: a página
- `data.json`: os dados da agenda (demandas, digital, site, container, onboarding, concluídos)
- `.nojekyll`: faz o GitHub Pages servir os arquivos como estão

## Como atualizar

Troque o `data.json` por uma versão nova (Add file → Upload files) e faça o commit.
A página atualiza sozinha em 1 a 2 minutos.
